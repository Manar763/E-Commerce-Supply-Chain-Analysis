# E-Commerce & Supply Chain Data Analysis

## Project Overview

This project is an end-to-end data analysis project that covers the complete journey from raw data to actionable business insights.

The main objective was to apply data analysis concepts in a practical environment by exploring, cleaning, modeling, transforming, analyzing, and visualizing the data using multiple tools and technologies.

---

## Project Workflow

### 1. SQL Data Exploration

We started by exploring the dataset using SQL to understand its structure, identify the main entities, examine data patterns, and investigate relationships between different tables.

This stage helped us understand the data and identify the key business areas that could be analyzed.

### 2. Data Cleaning Using Python

The next step was data cleaning using Python.

We prepared the raw data by identifying and handling data quality issues, removing irrelevant or redundant information, and improving data consistency to ensure that the dataset was reliable and ready for analysis.

### 3. Data Modeling Using SQL

After cleaning the data, we focused on building a structured data model using SQL.

This stage included applying concepts such as:

- Normalization
- Primary and Foreign Keys
- Table Relationships
- Data Integrity
- Business Queries

The goal was to create a reliable structure that could support accurate analysis and reporting.

### 4. Data Transformation and Star Schema

Using Power Query, we transformed and prepared the data for visualization.

We then designed a Star Schema consisting of a central Fact Table connected to multiple Dimension Tables. This structure helped organize the data efficiently and provided a strong foundation for analytical reporting.

### 5. Excel Data Analysis

Excel Pivot Tables were used to explore the data from different perspectives and identify additional patterns and insights.

This stage helped us perform quick exploratory analysis and validate some of the results before building the final dashboard.

### 6. Power BI Dashboard

Finally, we brought the different stages together in Power BI to develop an interactive business intelligence dashboard.

The dashboard includes:

- Key Performance Indicators (KPIs)
- Interactive Visualizations
- Slicers and Filters
- Drill-Down Analysis
- Geographic Maps
- Sales and Profit Analysis
- Customer Analysis
- Product Performance Analysis
- Orders and Delivery Analysis

## Project Outcome

This project provided practical experience in connecting the different stages of the data analysis process into one complete workflow.

Rather than studying each concept separately, we applied them together to transform raw data into a structured analytical model and, ultimately, into an interactive dashboard that can be used to explore business performance and generate meaningful insights.
